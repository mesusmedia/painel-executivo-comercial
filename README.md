# 📊 Painel Executivo Comercial — Mesus Media

Dashboard visual para acompanhamento diário de leads, funil de conversão e integridade de conexões WhatsApp das clínicas parceiras.

## 🚀 Funcionalidades
- **KPIs Consolidados:** Total acumulado, volume do mês corrente e leads do dia.
- **Alertas Operacionais:** Identificação imediata de canais desconectados (WhatsApp/Evolution API).
- **Gráficos Visuais:** Top 10 contas por volume e distribuição por segmento (Saúde, Odontologia, Estética).
- **Filtros Interativos:** Busca rápida por nome/ID e segmentação por status operacional (*Alta Tração, Moderado, WhatsApp Off, Sem Leads*).

## 🔒 Segurança e Privacidade
- Este repositório contém **exclusivamente** a camada de apresentação visual (HTML, CSS e JS puro).
- **Nenhuma chave de API, credencial ou token sensível** está presente no código.
